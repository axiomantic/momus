Install Momus

Three-step setup: create the GitHub App, save its private key, and run one command per target repo. The bot then posts AI PR reviews with inline comments and an APPROVE / REQUEST_CHANGES verdict.

1. Where will Momus run?

Pick the account that owns the repositories you want reviewed. The GitHub App is created under that account.

Personal account

Use this if the repos are owned by your user (e.g. your-name/some-repo).

Organization

Use this if the repos are owned by an org (e.g. my-org/some-repo). You need org-admin permission to create Apps under the org.

Why two paths? GitHub keeps secrets and Apps separate per account. Personal repos use repo-level secrets; orgs can use either repo-level or org-level (via --org-secrets in the install script).
